Afin de faire fonctionner les DLCs sur votre 3DS hackée, réalisez les étapes suivantes (si vous avez une 3DS japonaise, elles ne sont peut-être pas nécessaires) :

1. Récupérez le fichier luma.zip (qui se trouve dans la release avec les patchs).
2. Extrayez-le sur la carte SD de votre 3DS de sorte à ce que les dossiers 0004008C0F14AD00 et 000400000F14AD00 se trouvent dans le dossier luma/titles (en partant de la racine de la carte SD)
3. Lancez le menu luma en allumant votre console tout en appuyant sur SELECT. Si ce n'est pas déjà fait, cochez "Enable game patching", puis "Save and exit".
4. Lancez le jeu et essayez d'accéder aux DLCs. Si vous êtes renvoyé(e) sur l'écran titre, revérifiez les étapes 2 et 3.
