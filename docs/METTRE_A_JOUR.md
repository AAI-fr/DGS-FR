
# Mettre à jour le patch
## Nintendo 3DS
**IMPORTANT** : Il faut faire les étapes suivantes avant d'installer une nouvelle version du jeu pour ne pas perdre votre sauvegarde. Cette manip est destinée à être utilisée sur 3DS hackée.

 - Depuis le menu HOME, ouvrir l'app Checkpoint.
 - Si vous ne trouvez pas le jeu dans la liste, maintenez B pour la mettre à jour.
 - Sélectionnez le jeu -> New... -> Backup -> Yes -> entrez un nom reconnaissable et appuyez sur OK.
 - Installez la nouvelle version du patch avec FBI.
 - Lancez le jeu et démarrez une nouvelle partie ; sauvegardez dès que vous le pouvez.
 - Revenez sur checkpoint, choisissez la sauvegarde créée précédemment -> Restore -> Yes.
 - En lançant le jeu, vous retrouverez votre sauvegarde.

## Steam
- Dans Steam, clic droit sur The Great Ace Attorney Chronicles -> Propriétés -> Fichiers intallés -> Vérifier l'intégrité des fichiers du jeu.
- Appliquez le nouveau patch.

## Nintendo Switch
Sauf indication contraire, vous pouvez simplement appliquer le patch et remplacer les anciens fichiers par les nouveaux.
